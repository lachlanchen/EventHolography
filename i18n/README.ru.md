[![License: Apache-2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](../LICENSE)

Репозиторий с материалами проекта **Event-assisted Holographic Imaging**.

> Сохранённое исходное описание проекта (каноническая база):
> `The repo for the paper Event-assited Holographic Imaging`

## Обзор 🔍

`EventHolography` на данный момент является репозиторием, ориентированным прежде всего на документацию, вокруг темы статьи/проекта **Event-assisted Holographic Imaging**.

На момент написания репозиторий в основном содержит:

- Минимальный корневой README (здесь расширен для ясности)
- Лицензию Apache 2.0
- Проектный `.gitignore`
- Каталог `i18n/` для многоязычных вариантов README

Исходный код, манифест зависимостей или запускаемый пайплайн пока не закоммичены.

## Возможности ✨

- Чётко определённые идентичность и область проекта для исследований event-assisted голографической визуализации
- Лицензирование Apache 2.0 для открытого использования и вклада
- Готовая к многоязычности структура документации через `i18n/`
- Расширенная структура README для будущего добавления кода/данных
