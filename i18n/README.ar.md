المستودع الخاص بمواد مشروع **Event-assisted Holographic Imaging**.

> الوصف الأصلي للمشروع (محفوظ كمرجع أساسي):
> `The repo for the paper Event-assited Holographic Imaging`

## نظرة عامة 🔍

يُعد `EventHolography` حاليًا مستودعًا يركز على التوثيق أولًا، ويتمحور حول موضوع الورقة/المشروع **Event-assisted Holographic Imaging**.

في وقت كتابة هذا الملف، يحتوي المستودع بشكل أساسي على:

- ملف README أساسي في الجذر (تم توسيعه هنا لزيادة الوضوح)
- ترخيص Apache 2.0
- ملف `.gitignore` على مستوى المشروع
- مجلد `i18n/` لإصدارات README متعددة اللغات

لا توجد حاليًا شيفرة مصدر، أو ملف تعريف تبعيات، أو خط أنابيب قابل للتشغيل ضمن الملفات الملتزم بها.

- تعريف واضح لهوية المشروع ونطاقه في أبحاث التصوير الهولوغرافي المدعوم بالأحداث

## استكشاف الأخطاء وإصلاحها 🩺

### «لا يوجد شيء للتشغيل بعد»

هذا متوقع في الحالة الحالية. لم يتم الالتزام بأي سير عمل تنفيذي بعد.

### «كنت أتوقع ملفات README مترجمة»

المجلد `i18n/` موجود، لكنه قد لا يحتوي ملفات لغات بعد. أضف ملفات README الخاصة بكل لغة فيه عند إعدادها.

يتضمن الوصف الأصلي `Event-assited` (محفوظ حرفيًا). والتهجئة المفضلة في النصوص الجديدة هي `Event-assisted`.
