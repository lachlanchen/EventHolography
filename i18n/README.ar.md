<a id="overview-"></a>
## نظرة عامة 🔍

`EventHolography` هو مستودع **موثق أولاً** مخصص لثيم المشروع/المقال **Event-assisted Holographic Imaging**.

في لقطة هذا المستودع حاليًا، يُنظر إليه كمركز تعريف للمشروع والتواصل أكثر من كونه حزمة قابلة للتشغيل.

- الحالة الرسمية: بنية توثيقية للبحث في مرحلة مبكرة
- التركيز العام: سياق الورقة البحثية، افتراضات الإعداد، وإرشادات متعددة اللغات
- النطاق: بنية المستودع، عملية المساهمة، وجاهزية المساهمة للكود/البيانات مستقبلاً

<a id="features-"></a>
## المزايا ✨

- هوية واضحة لمواد مشروع Event-assisted Holographic Imaging
- ترخيص Apache 2.0 لإعادة الاستخدام المفتوحة والمرنة
- بنية README جاهزة للتعدد اللغوي (`i18n/`)
- توضيح واضح لوضعية التوثيق الأول لـالمستخدمين والمساهمين
- بنية متوافقة مع المستقبل لإضافة مجموعات البيانات، السكربتات، نقاط التحقق، وإرشادات إمكانية التكرار لاحقًا

## هيكل المشروع 🗂️

```text
EventHolography/
├── README.md
├── LICENSE
├── .gitignore
├── i18n/
└── .auto-readme-work/
```

ملاحظات:

<a id="troubleshooting-"></a>
## استكشاف الأخطاء 🩺

### "لا يوجد شيء للتشغيل بعد"

هذا متوقع في الحالة الحالية. لا توجد حالياً سكربتات قابلة للتشغيل أو إعدادات أو دفاتر أو مجموعات بيانات ملتزمة.

### "أين توجد ملفات README المترجمة؟"

راجع دليل `i18n/`. إذا كانت لغة الهدف مفقودة، أضف `i18n/README.<lang>.md` وزامن روابط التنقل بين اللغات.

### "لماذا يختلف تهجئة العنوان؟"

الجملة الأصلية في الملاحظات الأمامية هي `Event-assited` (بـ s واحدة)، ويتم الإبقاء عليها كما هي في السطر المقتبس. هذا الـ README يستخدم الإملاء الصحيح `Event-assisted` في النص المكتوب حديثًا.

### "هل أستخدم مجلد `.auto-readme-work/`؟"

اعتبره بيانات وصفية مولدة من أنابيب التوثيق. عادة ليس ضروريًا للمساهمين العاديين ما لم تكن تعمل على أتمتة التوثيق.
